## Mouse

| | |
|---|---|
| botão direito + arrastar | olhar em volta (cockpit) · orbitar a nave (fora) |
| `{{key:camera_free_look}}` + arrastar | girar a câmera no lugar |
| roda | aproximar e afastar, fora do cockpit |
| clique esquerdo | botões do painel do cockpit |

## Computador de bordo — `{{key:nav_panel}}`

| | |
|---|---|
| `TARGET` ◀ ▶ | o destino |
| `TARGET ORBIT` ◀ ▶ | a altitude da órbita de chegada |
| `SEARCH` | procura transferências, sem travar o jogo |
| `USE …` | escolhe entre as trajetórias achadas |
| `EXECUTE` | arma as queimas; o plano pilota |
| `CANCEL` | descarta o plano |
| `ATTITUDE` | os mesmos apontamentos das teclas, em botões |

## Instrumento FLIGHT

| | |
|---|---|
| centro | o nariz; anéis a 30°, 60°, 90° |
| verde | prógrado ○ · retrógrado ⊗ |
| ciano | normal ▲ · anti-normal ▼ |

## Lâmpadas

| | |
|---|---|
